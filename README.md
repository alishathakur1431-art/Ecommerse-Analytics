# E-Commerce Sales Analytics Dashboard

## Project Overview
This project focuses on analyzing E-Commerce sales data using Microsoft Power BI. It provides an interactive dashboard to understand sales performance, customer behavior, product performance, and order trends.

The dashboard helps convert raw sales data into meaningful insights through KPIs and visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features

### Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Sales

### Data Analysis & Visualizations
- **Sales by Category:** Analyzes sales across different product categories.
- **Monthly Sales Trend:** Shows sales performance over time.
- **Top 10 Products:** Identifies the best-performing products.
- **Sales by Payment Method:** Compares different payment methods.
- **Sales by Order Status:** Analyzes completed and other order statuses.
- **Sales by Age Group:** Understands customer age-group contributions.

### Interactive Features
- Category slicer for filtering dashboard data.
- Interactive charts and visual reports.
- KPI cards for quick business insights.

## Dataset
The project uses an E-Commerce sales dataset containing information about:
- Order ID
- Order Date
- Customer Details
- Product Name
- Category
- Quantity
- Total Sales
- Payment Method
- Order Status
- Age Group

## Project File
`ecommerce_analytics.pbix` – Power BI dashboard file.

## How to Run the Project
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `ecommerce_analytics.pbix`.
4. Explore the interactive dashboard and visualizations.

## Project Objective
The main objective of this project is to analyze E-Commerce sales data, identify business trends, understand customer purchasing patterns, and support data-driven decision-making.
